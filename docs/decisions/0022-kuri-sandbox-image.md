# 0022. Kuri's own sandbox image, published to GitHub's container registry

**Decided.** The sandbox's default image is Kuri's own, `ghcr.io/haruno19/kuri-sandbox`, built from `Sandbox/Dockerfile`: the official `python:3-slim` plus a short list of tools (poppler-utils, pandoc, ImageMagick, ripgrep, jq, git, sqlite3) and Python libraries (pypdf, pdfplumber, pandas, openpyxl, python-docx, Pillow, matplotlib). A GitHub Actions workflow in the same repository builds it for arm64 and publishes it whenever `Sandbox/` changes, tagged with the number in `Sandbox/VERSION`. Kuri pins that exact tag in `SandboxSettings.kuriImage`. Settings › Sandbox offers it and plain `python:3-slim` as presets, or any other reference.

**Why.** The sandbox has no network (decision 0012), so the model can only use what the image ships with, and `python:3-slim` ships almost nothing for the files people actually hand it: no way to get text out of a PDF, read a Word document or convert between formats. A curated image fixes that without giving the sandbox a network. The list stays short (the tools a person would reach for first, from Debian and PyPI, nothing personal or obscure), in the spirit of the dependency rules, and the model's instructions name what's there, since it can't install anything.

Publishing from the same repository keeps the recipe next to the code that pins it: a change to the image is a commit like any other, the workflow publishes it with the repository's own token (no secrets), and `SandboxImageTests` fails if the pinned tag and `VERSION` drift apart. A pinned tag, not `latest`, means an image reaches users only when Kuri asks for it, as with Containerization's exact pin.

**Cost.** The image is larger than `python:3-slim`, so setup downloads more and the sandbox takes more disk. Each change needs a `VERSION` bump in two places, and a release of Kuri that points at a new tag needs that tag published first. The package has to be public on GitHub for Kuri to pull it without signing in (a one-time switch in the package's settings).
