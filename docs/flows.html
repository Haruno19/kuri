How Kuri works

The flows inside the app: what each module asks of the others, which events the engine publishes, and what goes over the wire to inference providers and MCP servers. One sequence diagram per flow, drawn from the code as it is today.

Reading the diagrams

Columns are participants, top to bottom is time. The second line of each box is the module it lives in.

Arrows are numbered. Under each diagram, Code lists every step with the line that does it: for a call, where it's made; for a return or an event, where it's produced; for a step from outside Kuri, the code that receives it. Package paths start at Packages/KuriKit/Sources, app and CLI paths at the repository root; each comes with the code on that line.

External protocols

WithWhat Kuri uses
Inference serverPOST <baseURL>/responses with stream: true and store: false (stateless: the whole history every time), Authorization: Bearer from the provider's apiKey; the answer is a server-sent event stream.
Inference serverPOST <baseURL>/messages (Anthropic Messages) with stream: true, the whole history every time, x-api-key from the provider's apiKey, anthropic-version, adaptive thinking with summaries and automatic prompt caching.
Inference serverGET <baseURL>/models → { data: [{ id }] }, for model discovery (Anthropic's pages with has_more and after_id).
MCP serverJSON-RPC via the MCP Swift SDK. Client → server: initialize, notifications/initialized, tools/list, tools/call, notifications/cancelled. Server → client: notifications/tools/list_changed.
MCP transportstdio: newline-delimited JSON over the child's stdin/stdout, stderr kept as a log. Streamable HTTP: POST per message, Mcp-Session-Id, optional GET event stream, configured headers on every request.
Kata ContainersGET of the arm64 release tarball, once, for its kernel.
Image registriesOCI pulls, once each: Apple's vminit from ghcr.io and the sandbox image (Docker Hub by default).
Virtualization.frameworkThrough Containerization: one VM per conversation, no network device, folders shared with virtiofs, processes driven over vsock by vminitd.
Login shell$SHELL -ilc 'printf $PATH', once, so stdio servers find npx, uvx and friends when Kuri starts from Finder.
File system~/.config/kuri: config.json and mcp.json (watched), kuri.sqlite (WAL), blobs/, scratch/.
